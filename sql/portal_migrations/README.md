# Миграции портала

Эти миграции относятся к **центральной БД портала** `flovmp_portal`, не к
игровой БД `flovmp` на VDS проекта. `001_platform_core.sql` добавляет первые
таблицы модели Account → Project → Product/Entitlement из master spec:
продукты, планы, участников проекта, права доступа, lease, историю heartbeat
и аудит. Существующие таблицы лицензий и серверов не меняются.

Порядок для нового окружения: `portal_schema.sql`, затем миграции по номеру.
Для существующего портала: снять проверяемый backup `flovmp_portal`, сверить
текущую схему и применить только ещё не применённые миграции. `CREATE TABLE IF
NOT EXISTS` позволяет повторное выполнение, но не исправляет таблицу с
неверной структурой: схему нужно сверить отдельно. До появления runner и
боевого портала этот файл не запускается автоматически.

Отдельно предстоит подключить код API к новым таблицам, добавить версионирование
схемы и интеграционные тесты на MariaDB. Наличие таблиц не означает, что
entitlement уже влияет на выдачу релизов или лицензий.
