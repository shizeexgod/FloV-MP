# Архив компонентов FloV:MP

В данной папке хранятся выведенные из активной разработки прототипы и компоненты, которые заменены более современными технологическими решениями:

- **`FloridaV.Launcher-WPF/`** — первоначальный прототип десктопного лаунчера на чистом C# / WPF. Выведен из разработки 2026-09-04 в пользу связки **Electron (Chromium UI) + FloVMP.Launcher.Native (.NET 8 C#)**, обеспечивающей визуальный уровень Majestic/GTA5RP с аппаратным ускорением и эффектами.
