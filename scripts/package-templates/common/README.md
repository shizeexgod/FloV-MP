# FloV:MP — сервер

Версия пакета указана в файле `VERSION`.

Это готовый runtime-пакет для обычной лицензии (`deliveryMode: runtime-license`;
подробные поля — в `delivery.json`). Исходники платформы, `web/`, полноценный
launcher и внутренние инструменты в этот пакет не входят; source-kit выдаётся
отдельным продуктом.

## Установка на Linux (Ubuntu 22.04 / 24.04, Debian 12)

```bash
tar -xzf flovmp-server-*-linux.tar.gz
cd flovmp-server-*/
sudo ./install.sh --owner-sc <ваш SocialClubId>
```

Установщик сам:

1. проверяет целостность пакета;
2. ставит зависимости, .NET 10 и MariaDB;
3. копирует сервер в `/opt/flovmp`;
4. создаёт базу и отдельного пользователя со случайным паролем;
5. настраивает голосовой чат;
6. создаёт службы `flovmp` и `flovmp-voice`, открывает порты в ufw/firewalld;
7. включает ежедневную копию базы (04:30, хранится 14 дней, папка `backups/`);
8. запускает сервер и проверяет, что он поднялся.

Все параметры: `./install.sh --help`. Часто нужные:

| Параметр | Что делает |
|---|---|
| `--name "Мой RP"` | название сервера |
| `--slots 500` | максимум игроков |
| `--port 7788` | игровой порт |
| `--public-host 1.2.3.4` | внешний адрес, если определился неверно |
| `--no-db` | без базы данных |

Установку можно запускать повторно: ваши настройки сохраняются, а исправляются
только поломки (например, пароль базы).

## Запуск на Windows

Нужен [.NET 10 Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0).

1. Распакуйте `flovmp-server-*-windows.zip` во временную папку.
2. Запустите `install.cmd` (или `powershell -ExecutionPolicy Bypass -File install.ps1 -InstallDir C:\FloVMP`).
   Установщик сначала проверит SHA-256 каждого файла, затем скопирует платформу
   во временную staging-папку и повторно проверит её после установки. Настройки
   существующей установки не заменяются.
3. Запустите `FloVMP-Server.exe`. При первом запуске он создаст
   `config\flovmp.env`, `server\server.toml`, `voice\voice.toml`.
4. Сервер и голосовой чат работают в одном окне. Команды сервера
   (`setadmin`, `kick`, `reloadadmins` и другие) вводятся прямо в него.
5. Остановка — Ctrl+C или закрыть окно. Если сервер остановился сам, окно
   покажет причину и предложит перезапуск.
6. Подключение к серверу выполняется через встроенный Legacy b3889-клиент.
    Файл `connect.cmd` запускает `client-b3889\play.cmd`, проверяет установку
    FloV:MP и передаёт ему адрес сервера. Локальный адрес берётся из
    `server\server.toml`; пример для другого сервера — `connect.cmd 1.2.3.4:7788`.
    Внешний `FloVMP.Connect.exe` используется только как fallback для старых
    пакетов без `client-b3889`.

Папку можно держать где угодно, в том числе в пути с русскими буквами.

Если база подключена, окно сервера раз в сутки само сохраняет копию базы в
`backups\` (хранится 14 дней). Вручную — `scripts\backup-db.cmd`.

База данных на Windows необязательна: без неё права и баны хранятся
в файлах. Чтобы подключить MariaDB, создайте базу и пользователя (пример ниже)
и впишите их в `config\flovmp.env`:

```sql
CREATE DATABASE flovmp_server CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'flovmp'@'localhost' IDENTIFIED BY 'придумайте_пароль';
CREATE USER 'flovmp'@'127.0.0.1' IDENTIFIED BY 'придумайте_пароль';
GRANT ALL PRIVILEGES ON flovmp_server.* TO 'flovmp'@'localhost';
GRANT ALL PRIVILEGES ON flovmp_server.* TO 'flovmp'@'127.0.0.1';
```

Для игроков из интернета откройте в файрволе порт игры (UDP и TCP, по умолчанию
7788), порт клиентов GTA Legacy 1.0.3889.0 (UDP и TCP, порт игры + 10 — 7798:
вход, синхронизация и их голосовой чат) и голоса alt:V (UDP 7895), а в `server\server.toml` в секции `[voice]` впишите внешний IP в
`externalPublicHost`.

## Игроки: GTA V Legacy 1.0.3889.0

Текущая версия GTA V у игроков — Legacy **1.0.3889.0**. Для неё в пакете есть
собственный клиент FloV:MP — папка `client-b3889/`. Раздайте её игрокам целиком:

1. игрок запускает `install-client.cmd` — он найдёт игру, поставит ScriptHookV
   (с официального сайта, с проверкой контрольной суммы) и `FloVMP.asi`;
2. подключается: `play.cmd <IP сервера>:7788 <ник>` или клавишей **F9** в игре.

Клиент подключается к порту «игра + 10» (7798, UDP и TCP) — откройте его. Все
системы платформы работают для этих игроков так же: вход, баны (по ключу игрока,
железу и IP), права администратора, лицензия и слоты, чат, команды, F3/F4/F5,
голосовой чат (кнопка N, слышно в радиусе 25 м — `FLOVMP_VOICE_RADIUS`,
`/vmute` глушит).
ID игрока для прав — число из строки `ID игрока ...` в логе сервера при его входе
(`setadmin sc:<число> 8`).

Настройки шлюза в `config/flovmp.env`: `FLOVMP_NATIVE=off` — выключить,
`FLOVMP_NATIVE_PORT=<порт>` — другой порт (тогда игрокам нужно указывать его
при подключении: F9 → `IP:порт`).

## Настройки без программирования: `server/config/client.cfg`

Файл создаётся при первом запуске, у каждой строки есть пояснение. Здесь
настраивается всё, что платформа показывает игрокам:

- мир: прохожие, трафик, машины у обочин, полиция, поезда, погода, время;
- появление: точки спавна, модель, здоровье, броня, возрождение;
- интерфейс GTA: мини-карта, полоска способности, названия районов, колесо
  оружия, пауза на Esc, маркеры игроков, водяной знак, цвет акцента;
- ники над игроками: дальность, ID, полоски здоровья и брони, значок голоса,
  метка ADMIN, цвет, «Nick_Name» → «Nick Name»;
- чат и консоль F8: строки, затухание, время, ширина, длина, тема консоли;
- голос: включён ли, радиус, кнопка;
- загрузочный экран: заголовок, цвет, подсказки;
- заголовок окна игры у игроков (`window.title`, `{server}` — имя сервера);
- клавиши чата, консоли и инструментов администратора;
- производительность: дальность видимости игроков и их число у каждого.

После правки — команда `reloadsettings` в консоли сервера: игроки получат
изменения сразу, без перезахода. Ошибка в строке не ломает сервер — в журнал
пишется замечание и берётся значение по умолчанию. Новые ключи из обновлений
платформы дописываются в конец файла, ваши значения не трогаются.

## Свой сервер: папка `gamemode`

При первом запуске (Windows) или установке (Linux) создаётся папка `gamemode` —
здесь пишется ваш сервер: C# на сервере и JavaScript у игроков. Платформа уже
даёт спавн, администрирование, баны, голос и чат; в `gamemode` — ваша игровая
логика. Как собрать и как устроено — `gamemode/README.md`.

- Windows: `gamemode\build.cmd`, затем перезапуск `FloVMP-Server.exe`.
- Linux: `sudo gamemode/build.sh --install-sdk --restart`.

## Лицензия

Пошагово — в `INSTALL.md`. Коротко: ключ `FLV-...` указывается при установке
(`install.ps1 -LicenseKey`, `install.sh --key`) или в консоли сервера командой
`license activate <ключ>`. Сервер сам активирует его у сервера лицензий FloV:MP,
сохраняет подписанный `license.flv` в корень установки и каждые 5 минут
подтверждает, что ключ действует. Без связи сервер работает до 24 часов. Если
ключ истёк, приостановлен или отозван, вход закрыт для всех, включая
администраторов. Состояние — команда `license` в консоли.

## Проверка движения игроков

Сервер сам сверяет координаты игроков и замечает телепорт, завышенную скорость
и полёт: это единственное, что подделанный клиент скрыть не может. По умолчанию
нарушение только пишется в лог. Чтобы сервер возвращал нарушителя на последнюю
честную позицию, поставьте в `config/flovmp.env`:

```
FLOVMP_ANTICHEAT=strict
```

Значение `off` выключает проверку. Администраторы из неё исключены — у них
NoClip по праву.

## Структура

| Папка / файл | Чьё | При обновлении |
|---|---|---|
| `server/` — движок, модули, ресурсы `flovmp-starter`, `flovmp-client` | платформа | заменяется |
| `voice/altv-voice-server` | платформа | заменяется |
| `sdk/` — сборки для компиляции и шаблон `gamemode` | платформа | заменяется |
| `scripts/`, `FloVMP-Server.exe`, `install.sh`, `start.sh` | платформа | заменяется |
| `sql/migrations/001–099` | платформа | добавляются новые |
| `gamemode/` и собранный `server/resources/gamemode/` | **ваше** | не трогается |
| `server/server.toml` | **ваше** | не трогается |
| `voice/voice.toml` | **ваше** | не трогается |
| `config/flovmp.env` | **ваше** | не трогается |
| `license.flv` | **ваше** | не трогается |
| `server/config/` (`admins.json`, `admin-commands.cfg`), `server/flovmp-data/` | **ваше** | не трогается |
| `server/resources/<ваши ресурсы>` | **ваше** | не трогается |
| `sql/migrations/100+` | **ваше** | не трогается |

Проверить, что файлы платформы целы (после ручного копирования или сбоя):
Windows — `scripts\check-files.cmd`, Linux — `sha256sum -c manifest.txt`.

Список файлов платформы с контрольными суммами — `manifest.txt`
(`manifest.json` — то же для программ обновления). Всё, чего нет в этом
списке, — ваше, и обновление это не трогает.

## Как стать администратором

- в `config/flovmp.env`: `FLOVMP_OWNER_SC=<ваш SocialClubId>` и перезапуск —
  на Linux то же делает `sudo ./install.sh --owner-sc <SocialClubId>`;
- в игре: `/claimowner <токен>` (токен — в окне сервера / выводе установщика и
  в `config/flovmp.env`; действует, пока нет ни одного администратора);
- в консоли сервера (окно `FloVMP-Server.exe`): `setadmin <ID игрока> 8`, а если
  игрока нет в сети — `setadmin sc:<SocialClubId> 8`;
- в базе данных — см. `sql/README.md`.

**Если база подключена, права берутся из неё** (таблица `admins`), а правка
`config/admins.json` уже ничего не меняет: файл переносится в базу только один
раз, при первом запуске с пустой таблицей. Выдавайте права командой `setadmin`
в консоли сервера или прямо в базе; `reloadadmins` перечитывает их.

Права действуют сразу при заходе на сервер: ни пароля, ни дежурства нет.
Список доступных команд — `/help`.

По умолчанию все админ-команды доступны только создателю сервера (уровень 8).
Нужны младшие администраторы — откройте `server/config/admin-commands.cfg`
(создаётся при первом запуске), поставьте нужным командам уровень пониже
(например, `kick 2`), выдайте помощнику этот уровень и выполните `reloadadmins`
в консоли сервера.

SocialClubId игрока виден в логе сервера при его подключении.

## Обновление

Linux: распакуйте новый пакет и запустите его `sudo ./install.sh`. Перед
заменой файлов делается копия прежней версии в `backups/`. Если новая версия
не запустится, установщик сам вернёт прежнюю.

Windows: остановите сервер, распакуйте новый архив во временную папку и снова
запустите `install.cmd`. Установщик проверит пакет, сохранит резервную копию
платформы и заменит только файлы из `manifest.txt`. Ваши файлы (см. таблицу
выше) в архиве отсутствуют и не будут перезаписаны.

## Порты

| Порт | Протокол | Назначение |
|---|---|---|
| 7788 | UDP + TCP | игра |
| 7798 | UDP + TCP | клиенты GTA Legacy 1.0.3889.0 и их голос (порт игры + 10) |
| 7895 | UDP | голосовой чат игроков |
| 7896 | — | связь игрового и голосового серверов; наружу открывать не нужно |

## Полезное

- Лог: `server/server.log`, голос: `voice/voice.log`.
- Службы (Linux): `systemctl status|restart flovmp`, `systemctl status flovmp-voice`.
- Консоль сервера (Windows, окно `FloVMP-Server.exe`): `online`, `kick`, `ban`,
  `unban`, `bans`, `setadmin`, `reloadadmins`, `license`, `perf` (замер тика).
  Заблокировать того, кого нет в сети: `ban sc:<SocialClubId> <дней> [причина]`.
- Копия базы: `scripts/backup-db.sh` (или `scripts\backup-db.cmd`).
- Удаление: `sudo ./install.sh --uninstall` (файлы и база остаются).
