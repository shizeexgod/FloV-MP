# Установка FloV:MP — лицензионная версия

Инструкция для владельца проекта, купившего лицензию FloV:MP. От вас нужны
**ключ лицензии** (выдаёт FloV:MP, вид `FLV-XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX`)
и компьютер или VDS, на котором будет работать сервер.

Ключ привязывается к серверу при первом запуске. Число серверов на ключ и
срок указаны в вашей лицензии. Перенести сервер на другую машину можно:
напишите в поддержку, и старый сервер отвяжут от ключа.

---

## 1. Что понадобится

| | Windows | Linux |
|---|---|---|
| Система | Windows 10/11 или Windows Server 2019+ (x64) | Ubuntu 22.04 / 24.04, Debian 12 |
| .NET | [.NET 10 Runtime x64](https://dotnet.microsoft.com/download/dotnet/10.0) | ставится установщиком |
| База данных | необязательна (MariaDB — по желанию) | MariaDB ставится установщиком |
| Память / диск | от 4 ГБ / 2 ГБ | от 4 ГБ / 2 ГБ |
| Интернет | нужен: сервер раз в 5 минут подтверждает лицензию | то же |

Порты, которые нужно открыть для игроков (в файрволе и у хостинга):

| Порт | Протокол | Зачем |
|---|---|---|
| 7788 | TCP + UDP | игра |
| 7798 | TCP + UDP | игроки на GTA V Legacy 1.0.3889.0 и их голосовой чат |
| 7895 | UDP | голосовой чат |

## 2. Установка на Windows

Три способа. Первые два сами скачивают последнюю версию с сервера FloV:MP,
проверяют её подпись и работают как установка «с нуля», так и как обновление.

### 2.1. Архив установки (в один клик)

1. Скачайте `http://188.127.229.224/cdn/flovmp-setup.zip`.
2. Распакуйте **весь** архив в папку, где будет жить сервер (например
   `C:\FloVMP`). Не запускайте файлы прямо из окна архиватора.
3. Двойной щелчок по `УСТАНОВИТЬ.cmd`.
4. Введите ключ лицензии. Дальше всё само: скачивание, проверка подписи,
   установка. Ключ и папка сохранятся в `настройки.txt` рядом.

Обновление — тот же `УСТАНОВИТЬ.cmd`: ключ уже сохранён, и если установлена
последняя версия, ничего не скачивается и не меняется.

### 2.2. Одной командой (PowerShell)

Зайдите в папку будущего сервера и выполните:

```powershell
cd C:\FloVMP
powershell -ExecutionPolicy Bypass -Command "iwr http://188.127.229.224/cdn/get.ps1 -OutFile get.ps1; .\get.ps1 -Key FLV-XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX"
```

Без `-InstallDir` сервер ставится **в текущую папку** — в ту, в которую вы
зашли командой `cd`. Обновление потом — та же команда без `-Key`
(`.\get.ps1`): ключ берётся из установленного `config\flovmp.env`.

### 2.3. Из архива пакета (без интернета на сервере)

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -InstallDir C:\FloVMP -LicenseKey FLV-XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX
```

Во всех трёх случаях установщик проверяет каждый файл пакета по контрольной
сумме, копирует сервер в выбранную папку и сохраняет ключ в
`config\flovmp.env`. Путь может быть с русскими буквами.

### Что будет с тем, что уже лежит в папке

- Файлы платформы перечислены в `manifest.txt` — только они заменяются.
  Перед заменой делается резервная копия рядом с папкой сервера
  (`.flovmp-backup-ДАТА`), и при любой ошибке прежняя версия возвращается.
- Ваши настройки, карты, `gamemode`, ресурсы, база и `license.flv`
  в `manifest.txt` не входят и не затрагиваются никогда.
- Если в папке уже стоит **чужой** сервер или мод: совпадений имён нет —
  FloV:MP встанет рядом и ничего чужого не тронет; совпадения есть —
  установка остановится и покажет список файлов, не изменив ничего.
  Продолжить, сохранив чужие файлы в резервную копию, можно ключом `-Force`.

### Запуск

Запустите `C:\FloVMP\FloVMP-Server.exe`. При первом запуске он создаст файлы
настроек и **активирует ключ**. В окне сервера появится строка:

```
[License] лицензия FLV-... (Ваш проект, тариф ...): до ..., осталось ... дн., слотов ...
```

Ключ не указали при установке — введите его прямо в окне сервера:

```
license activate FLV-XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX
```

## 3. Установка на Linux (VDS)

**Одной командой:** скачивает пакет по ключу, проверяет подпись и контрольную сумму.

```bash
curl -fsSLo flovmp-get.sh http://188.127.229.224/cdn/get.sh
sudo bash flovmp-get.sh --key FLV-XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX --owner-sc <ваш SocialClubId>
```

Обновление потом — та же команда **без ключа**: он берётся из
`/opt/flovmp/config/flovmp.env`. Если установлена последняя версия, ничего не
скачивается («Обновление не требуется»); поставить заново — `--reinstall`.

**Или из архива:**

```bash
tar -xzf flovmp-server-*-linux.tar.gz
cd flovmp-server-*/
sudo ./install.sh --key FLV-XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX --owner-sc <ваш SocialClubId>
```

Установщик ставит .NET 10 и MariaDB, создаёт базу со случайным паролем,
копирует сервер в `/opt/flovmp`, создаёт службы `flovmp` и `flovmp-voice`,
открывает порты и запускает сервер. Состояние лицензии:

```bash
sudo journalctl -u flovmp -n 50 | grep License
```

Часто нужные параметры: `--name "Мой RP"`, `--slots 500`, `--public-host <внешний IP>`.
Полный список — `./install.sh --help`.

## 4. Проверка лицензии

В консоли сервера (окно `FloVMP-Server.exe` на Windows):

| Команда | Что делает |
|---|---|
| `license` | состояние лицензии, лимит игроков, путь к файлу |
| `license activate <ключ>` | ввести или сменить ключ без перезапуска |

Как это работает:

- при активации сервер получает от FloV:MP файл `license.flv` (он лежит в
  корне установки) — подписанную лицензию на ваш ключ;
- каждые 5 минут сервер подтверждает, что ключ действует. Подтверждения
  хватает на 24 часа: кратковременные сбои интернета игроков не выкидывают;
- после продления срока или смены тарифа новый файл лицензии приходит сам,
  перезапуск не нужен.

Если лицензия недействительна, вход на сервер закрыт для всех, включая
администраторов. Сообщения в окне сервера:

| Сообщение | Что делать |
|---|---|
| `license.flv не найден` | введите `license activate <ключ>` |
| `ключ не найден — проверьте, что он введён без ошибок` | сверьте ключ символ в символ |
| `по ключу уже работает серверов: N из N` | лимит серверов исчерпан — напишите в поддержку, чтобы отвязать старый сервер |
| `ключ приостановлен` / `ключ отозван` | свяжитесь с FloV:MP |
| `срок ключа истёк` | продлите лицензию; после продления сервер откроется сам в течение 5 минут |
| `не удалось подтвердить лицензию ... более 24 ч.` | у сервера нет доступа в интернет к `188.127.229.224` (HTTP, порт 80) |

Не копируйте папку сервера на другие машины: это будет ещё один сервер в
лимите вашего ключа.

## 5. Первые шаги после установки

1. **Станьте администратором.** Впишите свой SocialClubId в `config/flovmp.env`
   (`FLOVMP_OWNER_SC=...`) и перезапустите сервер. Или зайдите в игру и
   выполните `/claimowner <токен>`: токен показан в окне сервера и лежит в
   `config/flovmp.env`. Игрокам на GTA Legacy 1.0.3889.0 права выдаются
   командой `setadmin sc:<ID игрока> 8` в консоли сервера (ID виден в журнале при входе).
2. **Название и слоты** — `server/server.toml` (`name`, `players`).
3. **Всё, что видят игроки** — `server/config/client.cfg`: мир, спавн, интерфейс,
   ники, чат, голос, загрузочный экран. После правки — `reloadsettings` в консоли.
4. **Карты и объекты** — файлы в `server/config/maps` (расстановки Menyoo `*.xml`
   или `*.json`), команда `reloadmaps`.
5. **Своя игровая логика** — папка `gamemode` (C#), см. `gamemode/README.md`.

## 6. Игроки

Для игроков на GTA V Legacy **1.0.3889.0** в пакете есть клиент — папка
`client-b3889`. Впишите адрес сервера в `client-b3889/server.txt` (пример —
`server.txt.example`) и раздайте папку игрокам. Игрок запускает
`install-client.cmd`, затем подключается ярлыком на рабочем столе. Подробно —
`client-b3889/README.md`.

## 7. Обновление

Новую версию устанавливайте поверх старой так же, как ставили:

- Windows — остановите сервер и запустите `install.ps1` из нового архива с тем же `-InstallDir`;
- Linux — `sudo bash flovmp-get.sh --key <ключ>` или `sudo ./install.sh` из нового архива.

Ваши файлы (`config/flovmp.env`, `server/server.toml`, `server/config/*`,
`license.flv`, `gamemode`, свои ресурсы, база) не трогаются. Перед заменой
делается резервная копия платформы; если новая версия не запустится, на Linux
установщик сам вернёт прежнюю.

## 8. Если что-то не так

- Журнал сервера: `server/server.log` (Windows) или `journalctl -u flovmp` (Linux).
- Целы ли файлы платформы: `scripts\check-files.cmd` (Windows) или
  `sha256sum -c manifest.txt` (Linux, в папке установки).
- Подробное описание сервера — `README.md` в этой же папке.

Обращаясь в поддержку, сообщите ключ (достаточно первых 12 символов), версию
из файла `VERSION` и последние 50 строк журнала.
