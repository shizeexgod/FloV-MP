# RolePlay Server — Готовый каркас проекта (FloV:MP Scaffold)

Поздравляем с началом разработки RP-проекта на базе мультиплеерного движка **FloV:MP**!
Данный дистрибутив представляет собой полностью готовый, автономный каркас игрового сервера.

---

## Быстрый старт (в 1 клик)

### На Windows:
1. Запустите файл `start.cmd` в корне проекта (или `scripts\start-server.cmd`).
2. Сервер запустится и будет ожидать подключения игроков на порту UDP 7788.

### На Linux (Ubuntu / Debian):
```bash
chmod +x start.sh scripts/*.sh
./start.sh
```

---

## Структура проекта

- **`server/`** — серверная среда (.NET 8, модули движка, скомпилированные сборки `FloVMP.Core.dll` и `FloVMP.Gamemode.dll`).
- **`client/`** — клиентские ресурсы и NUI интерфейсы (`index.js`, авторизация, HUD, инвентарь, чат, консоль разработчика).
- **`config/`** — конфигурация `server.toml` (настроен на 2000+ слотов) и пример переменных окружения `flovmp.env.example`.
- **`sql/`** — чистая SQL-схема базы данных MariaDB (`schema.sql`).
- **`scripts/`** — утилиты запуска, создания бэкапов БД и проверки лицензии.
- **`license.flv`** — криптографический файл лицензии сервера.

---

## Настройка собственного брендинга (White-Label)

Чтобы сменить отображаемое имя сервера для игроков:
1. Откройте `config/server.toml` и измените поле `name = "Ваше Название RP"`.
2. Или задайте переменную окружения `FLOVMP_SERVER_NAME="Ваше Название RP"`.

---

## Подключение базы данных MariaDB

1. Создайте базу данных в MariaDB:
   ```sql
   CREATE DATABASE flovmp_rp CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
2. Импортируйте схему:
   ```bash
   mysql -u root flovmp_rp < sql/schema.sql
   ```
3. Скопируйте `config/flovmp.env.example` в `config/flovmp.env` и укажите параметры подключения.
