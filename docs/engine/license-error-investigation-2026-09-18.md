# `FAILED_TO_VERIFY_GAME_LICENSE`: расследование 18.09.2026

## Факты

- Сервер FloV:MP и пакет AI-Testing принимают TCP/HTTP на `7788`.
- `license.flv` сервера валиден; в серверном логе лицензия определяется до
  подключения игрока. Это не отказ лицензии FloV:MP.
- Клиентский лог показывает `Game version: 3337 on EGS`, хотя установленный
  Epic Legacy содержит `GTA5.exe` `1.0.3889.0` и RPF b3889.
- Тот же лог содержит `Rpf version: 3889 differs from alt rpf version: 3521`.
- Затем клиент получает `FAILED_TO_VERIFY_GAME_LICENSE` и сервер не пишет событие
  подключившегося игрока. Ранее launcher-лог подтверждал: `Backup file GTA5.exe
  is valid` и `Backup file copied`.

## Причина первого отказа

Старый backup-flow подменял `GTA5.exe` кэшем b3337, оставляя установленные RPF
b3889. В результате игра запускалась в смешанном профиле, а проверка игрового
лицензионного контекста не могла завершиться корректно. Этот отказ не является
отказом лицензии FloV:MP и не доказывает, что чистый b3889-профиль не запускается:
тот же исторический лог дошёл до `Game Started` и TCP-подключения.

## Исправление в FloV:MP

1. `AltvToml` теперь пишет `autoBackup=false`.
2. `LocalCdn` на `/backup/update.json` возвращает пустой native-манифест
   `{"files":[]}` и не раздаёт Rockstar-binaries.
3. `GtaLaunchGuard` разрешает только hash-verified Epic Legacy b3889; все
   остальные Legacy-профили и Enhanced остаются заблокированы.
4. Native launcher больше не завершается коннектором на промежуточной строке
   `Launcher patch completed`: она предшествует инъекции client DLL.
5. `--allow-unsupported` сохранён только для отдельного диагностического прогона.

Проверка на текущей установке: SHA-256 `GTA5.exe`, `update.rpf` и `update2.rpf`
совпадают с b3889 Epic-профилем; запуск разрешён без изменения GTA-файлов.

## Что ещё требуется для настоящей поддержки b3889/Enhanced

Следующий обязательный шаг — end-to-end прогон чистого b3889: окно GTA остаётся
живым, client runtime подключается, сервер видит игрока, загружаются ресурсы,
работает авторизация и два клиента видят друг друга. Если именно на этом чистом
пути появится version-specific сбой, отдельный native adapter станет предметом
следующего раунда; подмена exe/RPF его не заменяет.
