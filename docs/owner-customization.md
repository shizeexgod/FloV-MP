# Что владелец сервера может изменить у себя

Справка по лицензионной версии FloV:MP: что настраивается файлами (без
программирования), что — своим кодом в папке `gamemode`, и чего платформа не
даёт менять.

Все пути — от корня установки (`C:\FloVMP` или `/opt/flovmp`).

---

## 1. Без программирования: `server/config/client.cfg`

Файл создаётся при первом запуске, у каждой строки есть пояснение. Меняется на
ходу: команда `reloadsettings` в консоли сервера — игроки получают новые
значения сразу, без перезахода. Ошибка в строке не роняет сервер: в журнал
пишется замечание, берётся значение по умолчанию.

| Раздел | Что настраивается |
|---|---|
| Мир | прохожие, трафик, припаркованные машины, полиция и розыск, поезда и самолёты, погода при старте, время, остановка часов |
| Метрики и оповещения | `metrics.log_interval_sec`, страница `metrics.http_port` / `metrics.http_bind` / `metrics.token`; оповещения: `alerts.webhook_url`, `alerts.admins_chat`, пороги `alerts.tick_ms`, `alerts.min_tick_rate`, `alerts.errors_per_window`, `alerts.memory_mb`, `alerts.hang_sec`, повторы `alerts.cooldown_min`; команда консоли `metrics` |
| Игроки | сохранение и восстановление при входе: `players.persistence`, `players.save_interval_sec`, что восстанавливать — `players.restore_position`, `players.restore_health`, `players.restore_model`, `players.restore_weapons`, `players.restore_dimension`; хранилище данных геймода — `players.data`; имя мира в базе — `world.name` |
| Античит | журнал подозрений с весами: `anticheat.notify_score` (предупредить администраторов), `anticheat.kick_score` (отключать; 0 — никогда), `anticheat.decay_per_minute`, веса `anticheat.weight_*`, списки `anticheat.weapon_blacklist`, `anticheat.ped_whitelist`, `anticheat.vehicle_blacklist` (имена через запятую), `anticheat.issued_weapons_only`, `anticheat.ammo_accounting`, `anticheat.timescale_ratio`; `/ac <ID>`, `/acforgive <ID>` |
| Транспорт | `vehicles.power` — множитель мощности двигателя (скорость и разгон), `vehicles.torque` — тяга, `vehicles.max_registered` — потолок машин реестра (по умолчанию 1000), `vehicles.abandoned_ttl_sec` — через сколько секунд убирать брошенную машину трафика, если рядом никого нет (300, 0 — никогда; машины `/car` и геймода сами не исчезают; клиенты 1.0.6+), `vehicles.register_traffic` — брать ли в реестр машины трафика, `vehicles.register_cooldown_sec`, `vehicles.enter_distance`, `vehicles.plate_format` — шаблон номера (`99AAA999`), `vehicles.persistence` / `vehicles.save_interval_sec` / `vehicles.restore_damage` / `world.name` — сохранение машин. Любой ключ можно поменять и из кода ресурса: `Alt.Emit("flovmp:settings:set", ключ, значение)` |
| Появление | точки спавна (можно несколько), модель персонажа, здоровье, броня, возрождать ли после смерти и через сколько |
| Интерфейс GTA | мини-карта, полоска способности, названия районов, название машины, колесо оружия, меню FloV:MP на Esc без остановки мира, маркеры игроков на карте, водяной знак, акцентный цвет |
| Ники над игроками | показывать ли, дальность, ID в скобках, полоски здоровья и брони, значок микрофона, метка ADMIN, цвет, масштаб и размеры полосок, цвета HP/низкого HP/брони, «Nick_Name» → «Nick Name» |
| Чат | включён ли, число строк, через сколько гаснут, время у сообщений, ширина, максимум символов, RP-команды (`/me`, `/do`, `/b`, `/s`, `/w`), приветствие при входе |
| Консоль F8 | включена ли, оформление: `obsidian`, `slate`, `glass` |
| Загрузочный экран | включён ли, заголовок, цвет полосы, подсказки внизу (свой список) |
| Голос | включён ли, радиус слышимости, клавиша разговора |
| Клавиши | чат, консоль, ESP, NoClip, телепорт на метку |
| Производительность | дальность видимости игроков, сколько игроков видно одновременно |

Пример: сделать машины вдвое мощнее и включить трафик —

```
vehicles.power = 2
world.traffic = on
```

затем `reloadsettings` в консоли сервера.

## 2. Сервер целиком: `server/server.toml`

Название сервера, игровой порт, число слотов (в пределах лицензии), пароль,
внешний адрес для голоса, список ресурсов. Меняется при перезапуске.

## 3. Настройки установки: `config/flovmp.env`

Ключ лицензии и адрес сервера лицензий, владелец сервера (`FLOVMP_OWNER_SC`),
подключение к базе данных, строгость проверки движения (`FLOVMP_ANTICHEAT`),
порт шлюза клиентов 3889 (`FLOVMP_NATIVE_PORT`), радиус голоса, телеметрия.

## 4. Права администрации: `server/config/admin-commands.cfg`

Для каждой команды платформы задаётся минимальный уровень администратора
(0 — всем, 8 — только владельцу). Создаётся при первом запуске, применяется
командой `reloadadmins`. Так делаются помощники: выдать уровень 2 и открыть
им `kick`, `mute`, `ban`.

Сами администраторы — командой `setadmin` в консоли, через `/claimowner` в
игре или в базе данных.

## 5. Карты и объекты: `server/config/maps`

Папка для карт. Поддерживаются:

- **`*.xml`** — расстановки Menyoo (Object Spooner → Save file) и Map Editor в
  формате Menyoo: объекты и NPC ставятся как в редакторе;
- **`*.json`** — свой формат: объекты, метки на карте, маркеры, 3D-надписи, NPC
  (пример — в `README.txt` этой папки).

Команда `reloadmaps` перечитывает папку без перезапуска: игроки получают
изменения сразу. Клиент сам создаёт объекты рядом с игроком и убирает вдали,
поэтому карта в десятки тысяч объектов не сажает FPS.

**Ограничение по своим моделям.** Модели должны быть в игре у игроков: сервер
раздаёт координаты, а не файлы моделей. Любая модель из GTA V работает сразу
(по имени или хэшу). Своя модель (машина, здание, персонаж, которых нет в игре)
требует, чтобы игрок поставил её себе как дополнение к игре — автоматической
раздачи таких файлов в платформе пока нет.

## 6. Своя игровая логика: папка `gamemode` (C#)

Ваш код рядом с платформой. Платформа уже даёт вход, спавн, администрирование,
баны, чат, голос и лицензию. В `gamemode` пишется игра: работы, дома, фракции,
экономика. Сборка — `gamemode\build.cmd` (Windows) или `gamemode/build.sh`
(Linux), затем перезапуск сервера.

Что доступно из вашего кода:

| Возможность | Событие |
|---|---|
| игрок вошёл в мир | `flovmp:player:ready` / `flovmp:native:ready` (ID, ник) |
| своя чат-команда | `flovmp:commands:register` → `flovmp:command` / `flovmp:native:command` |
| сообщение в чат игроку и всем | `flovmp:chat:to` (ID, текст), `flovmp:chat:all` |
| уведомление на экране | `flovmp:ui:notify` (ID, текст, мс) |
| меню с пунктами и ответом | `flovmp:ui:menu` (ID, меню, заголовок, пункты) → `flovmp:native:menuSelect` |
| своя клавиша | `flovmp:keys:bind` → `flovmp:native:key` |
| объекты, метки, маркеры, надписи, NPC | `flovmp:world:object` / `blip` / `marker` / `label` / `npc` / `remove` |
| точка появления и возрождение | `flovmp:settings:spawn`, `flovmp:settings:respawn` |
| смерть игрока | `flovmp:player:died` / `flovmp:native:died` |
| своя база данных | те же настройки подключения, свои миграции в `sql/migrations` с номера 100 |

Игроки на GTA V Legacy 1.0.3889.0 приходят в события номером (ID), а не
объектом: у них нет сущности движка alt:V. Подробности и примеры —
`gamemode/README.md`.

## 7. Клиент игрока

Папка `client-b3889` раздаётся игрокам. Владелец меняет в ней адрес сервера и
название (`server.txt`) — игрок получает ярлык на рабочем столе. Всё остальное
в клиенте (интерфейс, ники, чат, клавиши, загрузочный экран) настраивается с
сервера файлом `client.cfg`, чтобы у всех игроков было одинаково.

## 8. Чего менять нельзя

| Что | Почему |
|---|---|
| Название платформы в игре и заголовок окна (`branding.name`, `window.title`) | это FloV:MP; свой бренд — только с комплектом исходников (Source Kit) |
| Имя процесса игры (`GTA5.exe`) | это файл самой игры; его переименование ломает запуск. Видимое имя окна и значок платформа уже меняет |
| Сам клиент (`FloVMP.asi`) и серверные библиотеки платформы | заменяются при обновлении; изменения потеряются. Всё, что нужно менять, вынесено в настройки |
| Лимит слотов и число серверов сверх лицензии | проверяется сервером лицензий |
| Проверка лицензии | без действующего ключа вход закрыт для всех, включая администраторов |

## 9. Что обновление не трогает

`config/flovmp.env`, `server/server.toml`, `server/config/*` (включая
`client.cfg`, `admins.json`, `admin-commands.cfg`, `maps`), `license.flv`,
папку `gamemode` и собранный ресурс, ваши ресурсы в `server/resources`,
миграции с номера 100, данные и резервные копии.
