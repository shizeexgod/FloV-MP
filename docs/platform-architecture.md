# FloV:MP — платформенная архитектура (не готовый RP-сервер)

Уточнено владельцем 2026-09-10. FloV:MP = мультиплеер-**платформа** (движок + лаунчер),
которую продают RP-проектам. Платформа даёт возможность СОЗДАТЬ сервер и стабильную
игру. Владельцы серверов строят СВОИ системы. Мы НЕ поставляем готовый геймплей.

## Два уровня

### 1. Платформенная база (ships out-of-box, получает КАЖДЫЙ сервер)
Только инфраструктура:
- **Личность/аккаунты** — идентификация игрока (нужна для банов и хэндоффа лаунчера).
- **Бан-система** — HWID + HWID-Ex + Social Club + IP + подсеть /24 (+ MAC со стороны лаунчера). Флагман.
- **Войс** — проксимити-голос (`VoiceGridRouter` + встроенный войс alt:V).
- **Базовый чат** — обычные сообщения (без RP-команд).
- **Анти-чит** — движение/скорость/оружие/бой/транспорт (защита платформы).
- **Спавн** — появление в мире.
- **Удалённое управление** — приём команд из веб-кабинета (`RemoteServerAgent`).

### 2. RP-пример / SDK (НЕ платформа, отдельно, опционально)
Всё это — пример «что можно построить», не часть продукта:
экономика, инвентарь, фракции, жильё, документы, униформы, деньги-HUD,
RP-команды чата (`/me /do /pay /bank /faction`...), 8-уровневая RP-иерархия админов.
Сейчас ошибочно вшиты в «ядро» (`GamemodeResource`) — выносим в пример.

### Держава RP / Держава Онлайн
Базовый ТЕСТОВЫЙ сервер: полетать, посмотреть прогруз карты и лаги. На нём ничего
не строится. Урезать до платформенного минимума (спавн + мир), RP-начинку убрать
в пример.

## Статус реализации (Актуально на 2026-09-11)

- ✅ **Ядро разделено компилятором (Phase 1):**
  - `FloVMP.Platform` (библиотека без зависимостей от гейммода: античит, стример, пространственная сетка `SpatialHashGrid`, адаптивный менеджер тиков `AdaptiveTickManager`, БД, аккаунты, лицензирование).
  - `FloVMP.Runtime` (мост к alt:V C#-модулю, `LicenseGate`, `Safe.cs`).
  - `FloVMP.Gamemode` (RP-логика, фракции, экономика — собирается против DLL платформы, исходники платформы заказчикам не передаются).
- ✅ **Голосовой сервер (External Voice 16.4.39):**
  - Развёрнут в `/opt/flovmp-voice` на VDS.
  - Служба `flovmp-voice.service` связана директивой `PartOf=flovmp.service` — рестарт игрового сервера гарантированно перезапускает голосовой процесс, исключая «тихое» отваливание голоса.
- ✅ **Криптографическое лицензирование (RSA-2048):**
  - Файл `license.flv` подписывается приватным ключом SHA-256 with RSA-2048.
  - `LicenseGate.cs` валидирует подпись автономно (падение веб-портала не гасит сервер лицензиата).
  - Проверка вызывается в `Attach()` каждого платформенного модуля.
  - Вшит водяной знак для отслеживания утечек дистрибутива.
- ✅ **Масштабируемость до 5000+ онлайна:**
  - Лимит слотов снят в Enterprise (режим «Безлимит»).
  - Хеш-сетка `SpatialHashGrid<T>` ускоряет пространственные выборки до $O(1)$.
  - `AdaptiveTickManager` масштабирует частоту обновлений в зависимости от нагрузки.
- ✅ **SaaS Веб-Портал и 3 способа авто-поставки:**
  - 1-клик генерация и скачивание `license.flv`.
  - Установщик в 1 команду: `curl -sSL https://flov-mp.ru/install.sh | bash -s -- --key FLV-...`.
  - Управление префиксами серверов (`[DEV]`, `[TEST]`, `[PROD]`) и лимитами слотов прямо из личного кабинета.
