ЧТО НАЙДЕНО И УЖЕ ИСПРАВЛЕНО
=============================

1. Критическая утечка игрового bridge в iframe.
   Раньше window.mp внедрялся во все frame, включая внешний контент. Теперь
   bridge доступен только main frame. Есть тест с реальным Chromium iframe.

2. Возможный «рваный» CEF-кадр.
   Клиент мог загрузить в GPU shared memory во время записи следующего кадра.
   Теперь dirty rectangle сначала копируется в staging buffer, seqlock
   повторно проверяется и только стабильный кадр попадает в GPU и alpha-test.

3. Фиктивные browser.orderId и browser.inputEnabled.
   Теперь это настоящие native setters. Render и hit-test используют один
   устойчивый z-order; inputEnabled=false пропускает ввод сквозь страницу.

4. Прозрачный overlay перехватывал мышь.
   После первого валидного кадра полностью прозрачный пиксель больше не
   захватывает ввод. Fallback оставлен только до появления первого кадра.

5. Данные браузера переходили между серверами.
   Удалён постоянный общий профиль. Cookies/localStorage живут в памяти одного
   server package, request context пересоздаётся при смене package root.
   Регрессия доказывает, что второй сервер не видит localStorage первого.

6. Терялись команды сразу после new Browser().
   URL, active/visible, frameRate и destroy теперь ждут OnAfterCreated.
   Ранний destroy не оставляет orphan Chromium. Добавлен frameRate 1–60;
   скрытые страницы не копируют кадры в GTA.

7. Runaway CEF-страница могла забить игровой тик событиями.
   Лимиты: 240 mp.trigger/с на browser и 1000/с суммарно, с warning вместо
   зависания. Очередь ограничена корректно. Named pipe дописывает весь буфер
   при частичном WriteFile с обеих сторон.

8. Не был доказан recovery после падения CEF host.
   Fault-injection реально завершает host и проверяет цепочку HostLost ->
   автоматический restart -> повторное создание страницы -> новая текстура.
   JS получает browserHostLost и browserHostRestored.

9. browserLoadingFailed терял диагностику.
   Теперь событие отдаёт (browser, errorCode, url).

10. scripts/fetch-cef-sdk.ps1 не проходил проверку кодировки PowerShell.
    Добавлен UTF-8 BOM; общий healthcheck снова зелёный.

[ЗАКРЫТО 26.09] Штатный Chromium sandbox
-----------------------------------------

Включён cef_sandbox.lib, CefScopedSandboxInfo передаётся CefExecuteProcess и
CefInitialize, no_sandbox=false. Healthcheck теперь отдельно запрещает возврат
несандбоксированной сборки. Параллельный прогон выявил второй дефект: общий
root_cache_path блокировал второй host singleton-lock CEF 120+. Теперь у каждой
жизни host отдельный incognito root; два тестовых клиента одновременно проходят
31/31 и 37/37, включая crash recovery. Штатный Shutdown сначала просит CEF
закрыться корректно и только при зависании завершает его принудительно; следующий
старт удаляет incognito-root уже умершего процесса.


[ЗАКРЫТО 26.09] Origin и network policy
----------------------------------------

Сеть CEF теперь закрыта по умолчанию. Точные `https/http/wss/ws` origins берутся
из `client_packages/browser-origins.txt`, который входит в SHA-256 digest
пакета; wildcard и URL с путём отбрасываются, http/ws дают предупреждение.
CEF parser нормализует origin. Policy применяется к main navigation,
subresource, download и redirect. Remote main page получает bridge только при
точном совпадении; iframe — никогда. Browser process независимо проверяет
PID_RENDERER, main frame и origin сообщения. Настоящий локальный HTTP regression
доказывает allowed UI/subresource, deny до сети и blocked redirect: 36/36.

Оговорка: отдельной криптографической подписи владельца у client_packages пока
нет; целостность — SHA-256 файлов + общий digest, объявленный игровым сервером.
Нельзя называть это подписанным manifest до появления server identity/signature.


[P0-2] Провести живой GTA b3889 E2E
-----------------------------------

Это обязательный release gate, который автотестами закрыть нельзя:
  - один сложный HUD + меню + прозрачный modal;
  - правильный z-order и click-through;
  - возврат мыши/клавиатуры игре после закрытия UI;
  - кириллица, clipboard, resize, DPI, alt-tab, fullscreen/windowed;
  - Esc-меню без паузы мира, F12 ничего не открывает;
  - уничтожение flovmp-cef.exe во время игры: HUD возвращается сам;
  - reconnect/смена сервера: cookies/localStorage не переходят;
  - замер FPS, p95/p99 frametime, RAM/VRAM и CPU до/после HUD;
  - два клиента видят один мир, урон и транспорт не ломаются при открытом UI.

Критерий:
  сохранён воспроизводимый сценарий, логи и видео/скрин; нет зависшего курсора,
  чёрного экрана, мерцания, потери ввода и заметной деградации frametime.

[ЗАКРЫТО 26.09] Уменьшить и контролировать расход browser-ресурсов
--------------------------------------------------------

Клиент и CEF host независимо ограничивают 12 browser и суммарную площадь
12×1920×1080. При 4K/множестве слоёв внутреннее разрешение пропорционально
снижается. `mp.browsers.stats` отдаёт count/visible, screen/render size, pixels,
приблизительную память, uploaded/dropped frames и upload time. Лишний слой
штатно отклоняется; integration-тест проверяет cap, pixel-budget, `frameRate=1`
и фактическую остановку композитинга для hidden browser.

Bounds/position/size и живой профиль hidden/1 FPS остаются отдельными задачами.
