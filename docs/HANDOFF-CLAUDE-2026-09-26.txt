КРАТКИЙ СТАТУС
===============

CEF/HUD уже не является пустым прототипом: есть отдельный sandboxed Chromium
process, mp.browsers API, несколько слоёв, прозрачность, ввод, восстановление
после падения host и изоляция данных разных серверов. Основные native и
Chromium-тесты зелёные. Но продукт ещё нельзя честно назвать полностью
проверенным: не пройден живой GTA Legacy 1.0.3889.0 E2E и не доказано, что
новые бинарники попали в установщик/CDN/VDS.

Текущий local HEAD на момент отчёта: 8ab0571
Текущий origin/master: ebe88c4

ВАЖНО: CEF-цепочка находится только локально. Если Claude работает не в
C:\FloV-MP на этом ПК, сначала нужен push/cherry-pick. Не собирать релиз из
origin/master: там этих исправлений пока нет.

Закрытые дефекты:

1. window.mp больше не внедряется во внешние iframe.
2. Убран разрыв кадра между shared memory и GPU: staging + seqlock.
3. browser.orderId/inputEnabled теперь реально влияют на render/hit-test.
4. Прозрачные пиксели после первого кадра не крадут мышь.
5. Сессии/cookies/localStorage не переносятся на другой сервер.
6. Команды сразу после new Browser() не теряются; ранний destroy безопасен.
7. Runaway UI не может бесконечно забивать игровой тик событиями.
8. После принудительного завершения flovmp-cef.exe HUD создаётся заново.
9. browserLoadingFailed отдаёт errorCode и URL.
10. CEF включён со штатным Windows sandbox; no_sandbox=false.
11. Параллельные клиенты не конфликтуют за Chromium singleton/cache lock.


ПОСЛЕДНЯЯ ЗАКОММИЧЕННАЯ ПРАВКА
==============================

Fail-closed origin/network policy для CEF:

- без client_packages/browser-origins.txt браузер не ходит в сеть;
- разрешаются только точные http/https/ws/wss origins, без wildcard/пути;
- policy применяется к main navigation, subresource, redirect и download;
- remote main page получает window.mp только при точном allowlist match;
- iframe никогда не получает bridge;
- browser process повторно проверяет renderer PID, main frame и origin;
- browser-origins.txt входит в обычный SHA-256 digest client package;
- настоящий локальный HTTP regression проверяет allow/deny/redirect.

Изменённые файлы этой правки:

  native/legacy-3889/client/cef-host/main.cpp
  native/legacy-3889/client/src/browser.cpp
  native/legacy-3889/client/tools/browser-test/main.cpp
  native/legacy-3889/client/CMakeLists.txt
  scripts/flovmp_healthcheck.py
  scripts/package-templates/common/sdk/client_packages/browser-origins.txt
  scripts/package-templates/common/sdk/template/README.md
  docs/owner-customization.md
  docs/roadmap.md
  docs/CEF-AUDIT-2026-09-25.txt
  docs/CODEX-CEF-HANDOFF-2026-09-25.txt

Оговорка: это контроль целостности пакета, а не криптографически подписанная
идентичность игрового сервера. Нельзя писать покупателю «подписанный manifest»,
пока не появится server identity/signature и доверенный корень в клиенте.

[P0] 1. Сохранить текущую работу

- Отделить origin-policy от параллельных web-изменений.

- Не трогать параллельные web/REDESIGN_* и другие чужие untracked docs.

[P0] 2. Живой GTA b3889 E2E
---------------------------

Обязательный сценарий на настоящей GTA Legacy 1.0.3889.0:

- чистая установка клиента, connect.cmd/play.cmd и фактический вход;
- два клиента видят друг друга, движение/урон/смерть/транспорт синхронны;
- HUD + меню + прозрачный modal, правильный z-order/click-through;
- мышь и клавиатура полностью возвращаются игре после закрытия UI;
- Esc открывает нужное меню без остановки сетевого мира;
- F12 не открывает Rockstar overlay;
- кириллица, clipboard, DPI, resize, alt-tab, fullscreen/windowed;
- завершить flovmp-cef.exe во время игры: HUD должен вернуться сам;
- reconnect/смена сервера: состояние браузера прошлого сервера не видно;
- снять FPS, p95/p99 frametime, CPU, RAM и VRAM до/после HUD.

До этого теста поддержку b3889 нельзя объявлять финально доказанной.

[P0] 3. Собрать и проверить реальный пакет
-----------------------------------------

- Чистая сборка из конкретного commit hash.
- В пакете должны быть новый FloVMP.asi, flovmp-cef.exe, libcef.dll,
  resources/locales и browser-origins.txt template.
- Проверить manifest/SHA-256, чистую установку и update поверх старой версии.
- Проверить uninstall: не удаляет GTA и пользовательские файлы.
- Только затем обновлять VDS/CDN/release tag.

[ЗАКРЫТО 26.09] 4. Ограничить ресурсы браузеров
------------------------------------

Сейчас допускается до 32 полноэкранных browser. Это опасно: один BGRA-кадр
1920x1080 — около 7.9 MiB, а фактически есть shared memory, staging, GPU texture
и сам Chromium.

Сделано после первоначального отчёта: hard cap 12 проверяется клиентом и CEF
host, общий pixel-budget — 12×1920×1080. На 4K/при множестве слоёв внутреннее
разрешение пропорционально снижается. `mp.browsers.stats` показывает count,
visible, screen/render size, pixels, приблизительную память, uploaded/dropped
frames и upload time. Лишний browser штатно отклоняется. Новые проверки:
CEF browser integration 47/47, JS 42/42. Отдельно доказано, что `frameRate=1`
ограничивает поток кадров, а `active=false` останавливает композитинг.

Живой профилинг hidden/1 FPS внутри GTA всё ещё входит в P0 E2E.

[ЗАКРЫТО 26.09] 5. Закончить API серверного кастома HUD
--------------------------------------------

Уже можно полностью задавать HTML/CSS/JS/Canvas/WebGL, ники, HP/armor, HUD,
меню, modal, z-order, ввод и FPS без изменения ASI.

После отчёта добавлены physical-pixel `bounds/setBounds/resetBounds`, явные
`focus/blur/focused`, responsive fullscreen и безопасный resize без клика по
старому alpha-buffer. Lifecycle: destroyed, crashed, restored и повторный
DomReady. SDK sample показывает HUD + modal + transparent click-through,
focus/blur и recovery. Проверки: Chromium 47/47, QuickJS/API 42/42.

[P1] 6. Полноценная подпись server package
------------------------------------------

Текущий aggregate digest приходит от игрового сервера и защищает от случайной
порчи/подмены в канале только в рамках доверия самому соединению. Для сильной
модели нужен подписанный manifest, доверенный public key/identity в клиенте,
версия/expiry/anti-rollback и ротация ключей. Это отдельная работа; не смешивать
её с уже готовым exact-origin allowlist.
