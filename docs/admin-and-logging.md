## 1. Система логов (всё логируется)

### Что логируем (категории, как в референсе)

| Категория | Примеры событий |
|---|---|
| Действия администрации | teleport (`metp`/`tp` c координатами), `healPlayer`, `revivePlayer`, `undemorgan`, выдача предметов/денег, кик/бан/мут, спавн транспорта |
| Аккаунты | регистрация, вход, смена пароля/почты, привязка, вход с нового IP/HWID |
| Персонажи | создание, удаление, переименование, смена пола/внешности |
| Баны / муты / арест / штрафы | кто, кому, срок, причина, кто снял |
| Деньги | наличные/банк — все дельты с источником (работа, магазин, перевод, админ) |
| Предметы / склад | появление, использование, дроп, передача, крафт |
| Транспорт | покупка, продажа, спавн, деспавн, взлом |
| Фракции / бизнесы / семьи / дома | создание, роспуск, вступление/исключение, повышение, казна, покупка/продажа |
| ID / имена | смена связок, кто менял |
| Мероприятия | старт/стоп, участники, награды |
| Убийства | кто кого, оружие, координаты, was-rp |
| Вопросы (Q&A) | вопрос игрока, кто ответил, ответ |
| Промокоды / бонус-коды | создание, активация, кем |

### Архитектура

```
C#-сервер: ILogSink (интерфейс)
   ├─ FileLogSink       — JSON Lines в flovmp-data/logs/<категория>/<дата>.jsonl (fallback, всегда)
   └─ DbLogSink         — INSERT в БД (основной), пачками, неблокирующий (Channel<LogEntry>)

LogEntry { id, ts_utc, category, action, actor (admin/system/player), target,
           details (json), ip, pos, server_node }

Веб-дашборд (отдельный сервис, C#/ASP.NET minimal API + фронт):
   /api/logs?category&actor&target&from&to&q&page   (курсорная пагинация)
   /api/logs/export (csv/jsonl)
   таблицы с сортировкой по колонкам (как в референсе), поиск по полям,
   пресеты фильтров, live-tail новых записей (SSE).
```

### Принципы

- **Неблокирующая запись** — лог не должен тормозить гейм-тик. Продюсер
  кладёт в `Channel`, консюмер пишет пачками.
- **Ничего не теряем** — при недоступности БД падаем на файловый синк,
  потом досылаем.
- **Ретеншн** — конфиг: горячие N дней в БД, холодное в архив (сжатые jsonl).
- **Единая точка** — `Log.Admin(...)`, `Log.Money(...)` и т.д., чтобы во
  всех системах вызов был однотипный (как в Florida V).
- **Иммутабельность** — записи только добавляются, не редактируются.

## 2. Админ-панель (в игре + веб)

### Доступ по уровням (роль → что можно)

Ориентир: SayonaraRP + скрин «Test / 9 level». Уровень админа = набор прав.

| Уровень (пример) | Права |
|---|---|
| 1 Хелпер | ответы на вопросы, чтение логов чата, `goto`/`gethere`, мут |
| 2 Модератор | + кик, варн, штрафные баллы, просмотр инвентаря, заморозка |
| 3 Админ | + бан, выдача/снятие денег и предметов (лимит), управление транспортом |
| 4 Ст. админ | + фракции/бизнесы/семьи (состав, казна, ранги), мероприятия |
| 5 Гл. админ / разраб | + всё, редактирование правил, доступ к «Проверкам», экспорт |

Права — гранулярные флаги, уровни — пресеты флагов (в конфиге/БД).

### Разделы (по скрину + Sayonara)

- **Главная / инфопанель** — онлайн, аккаунтов, персонажей, домов,
  транспорта, за сутки. Быстрые действия.
- **Игроки** — поиск (UUID/имя/фамилия/банк), карточка: аккаунт, персонажи,
  финансы, инвентарь, наказания, сессии, действия (тп, хил, revive,
  выдать/забрать, кик/бан/мут).
- **Команды сервера** — состав администрации, уровни, кто активен.
- **Отпуска** — заявки/график админов.
- **Наказания** — баны/муты/аресты/штрафы, история, снятие.
- **Модерация → Штрафные баллы**.
- **Экономика → Транспорт / Предметы / Деньги** — справочники + операции.
- **Контент → Обучение / Семьи / Фракции / Бизнесы** — CRUD, состав,
  ранги, казна.
- **Правила** — государственные / общие, редактор (уровень 5).
- **Статистика / Репорты** — графики (репорты по дням/часам, ср. время
  ответа/решения, активные админы), экспорт.
- **Логи** — всё из раздела 1, с фильтрами.
- **Проверки** — очередь проверок игроков (жалобы/подозрения), назначение,
  вердикт, привязка к логам.

### Реализация

- **В игре**: NUI-ресурс `flovmp-admin` (HTML/JS, стиль FloV:MP). Открытие
  по команде/биндезу для тех, у кого есть флаг. Сервер отдаёт только
  разрешённые разделы/данные (проверка прав на КАЖДЫЙ запрос, клиенту не
  верим).
- **Веб**: тот же API, что дашборд логов, + разделы управления. Аутентификация
  админов отдельная (не игровая), 2FA желательно.
- **Дизайн**: минимализм, тёмная тема, аккуратные таблицы с сортировкой,
  левое меню-дерево (как на скрине), акцент `#ff3d8a`. НЕ Gemini-эстетика.
- **Аудит самой панели**: любое действие в панели → запись в логи
  (категория «Действия администрации»).

## Порядок работ (не сейчас)

1. Ядро MP → стабильно (текущий фокус).
2. Перенос геймплея Florida V (логика-в-логику).
3. `ILogSink` + файловый синк — вводится ВМЕСТЕ с переносом систем
   (каждая система при портировании сразу логируется).
4. БД-синк + веб-дашборд логов.
5. Права/уровни + игровая NUI-панель (разделы по мере готовности систем).
6. Веб-панель управления.
7. Раздел «Проверки», статистика/репорты.

Ничего из Florida V при переносе не терять: каждая механика → её логи → её
раздел в панели.
