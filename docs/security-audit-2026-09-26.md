# Аудит безопасности: проверенные находки

Это не утверждение о полной безопасности платформы. Ниже только случаи,
подтверждённые кодом и тестами в этом раунде.

| Статус | Находка | Исправление и проверка |
|---|---|---|
| Подтверждено, исправлено | FLOV/2 принимал строку длиннее 4096 байт, если `\n` попадал в уже считанный сетевой буфер | Лимит проверяется перед декодированием каждой строки; `SingleBufferOversizedLineDisconnects` |
| Подтверждено, исправлено | Некорректный UTF-8 заменялся `�` и мог попадать в ники/события | Строгое декодирование и отключение клиента; `InvalidUtf8DisconnectsWithoutDeliveringMessage` |
| Подтверждено, исправлено | CEV/CEVS проверял JSON по числу символов, но не по реальному размеру UTF-8 после экранирования; не требовался JSON-массив | `NativeClientEventPolicy` проверяет имя, массив и предел 4096 байт в обоих направлениях; 6 профильных тестов |

Открытая проверка: `client_packages` и CEF `package://`, origin allowlist и
`mp.invoke`; `/claimowner` с реальными правами; доверие `X-Real-IP` в nginx;
нагрузка на очередь событий при тысячах клиентов. Для них нужен отдельный
разбор и, где возможно, интеграционные тесты. Не обозначать их «зелёными» по
одному health-check.
