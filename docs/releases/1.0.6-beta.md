## FloV:MP 1.0.6 — Beta

Всё, что сделано после 1.0.5-beta. Обновление сохраняет ваши настройки,
`gamemode`, лицензию, базу и свои ресурсы — меняются только файлы платформы
(перед заменой делается резервная копия, при ошибке — откат).

**Клиент игроков тоже обновился** (`client-b3889`): раздайте игрокам новый
`client-b3889.zip`. Старый клиент к серверу 1.0.6 подключается, но машины
видит по старой схеме, а сервер попросит обновиться.

### Загрузочный экран

- Новый загрузочный экран: фон, логотип, фирменные шрифты, новая полоса
  прогресса; этапы загрузки показываются по факту событий, а не по таймеру.
- Свой фон и логотип сервера по ссылке: `loading.background_url` и
  `loading.logo_url` (http/https, JPEG или PNG до 16 МБ). Клиент скачивает
  картинку один раз в кэш; чтобы сменить её, укажите новый адрес.
- Если сервер не пустил игрока (бан, лицензия, нет мест) — понятный экран
  отказа с причиной вместо пропавшей загрузки.
- Подсказки на загрузочном экране убраны: `loading.tips` больше не используется.

### Транспорт на сервере (главное в этой версии)

- Машинами владеет сервер: реестр машин, места в салоне, водитель, здоровье,
  номера. Машина больше не исчезает у остальных, когда из неё вышел водитель.
- Машины, созданные сервером или вашим кодом, не удаляются сами никогда;
  брошенный трафик убирается, только когда он пуст и рядом никого нет.
- `/dv` работает и снаружи машины, в пределах 10 м.
- Машины сохраняются между перезапусками сервера (MariaDB или файл
  `flovmp-data/vehicles.json`), у каждой свой мир — несколько серверов на
  одной базе друг другу не мешают.
- API для вашего `gamemode`: создать машину, посадить или высадить игрока,
  задать здоровье и номер, события «сел/вышел/повреждена/уничтожена».
  Справочник — `gamemode/README.md`, раздел «Транспорт».

### Сохранение игрока

- Позиция, здоровье, броня, модель и оружие сохраняются при выходе и
  возвращаются при входе.
- Хранилище данных `gamemode` на каждого игрока (ключ → значение): деньги,
  инвентарь, квесты. Загружается в фоне и не тормозит сервер; быстрый
  перезаход не теряет последние записи.

### Античит, вторая линия

- Журнал подозрений с весами: очки копятся и со временем тают, пороги
  «сообщить» и «кикнуть» настраиваются (кик по умолчанию выключен).
- Белые и чёрные списки оружия, моделей персонажей и машин.
- Учёт патронов: попаданий больше, чем выдано, — подозрение.
- Детект ускорения времени на клиенте (speedhack).
- Команды администратора `ac` (журнал игрока) и `acforgive` (сбросить).
- Исправлены три неверных хэша в чёрном списке оружия (railgun, raypistol,
  emplauncher) — раньше они не ловились.

### Метрики и оповещения

- Метрики сервера: такт, игроки, трафик, очереди записи в базу; строка в
  журнале, JSON и формат Prometheus (`metrics.*` в настройках, доступ по токену).
- Оповещения владельцу в Discord, Slack или любой webhook и администраторам
  в игре: зависание, падение (видно при следующем старте), долгий такт,
  всплеск ошибок, расход памяти (`alerts.*`).

### Мир: интерьеры и IPL

- Части карты (IPL) и оформление интерьеров включаются из настроек
  (`world.ipls`, `world.ipls_remove`), из карт в `server/config/maps` и из
  кода. Онлайн-интерьеры открываются через `world.mp_map`.
- При выходе с сервера клиент возвращает карту игры в исходное состояние.

### Бой и синхронизация (не вошло в 1.0.5-beta)

- Снайпер на дальности видимости больше не «нерегает».
- Очередь снимка мира ушедшего игрока освобождается сразу.
- Броня отправляется только при изменении — меньше трафика.
- В журнале клиента видно, что перехват клавиши Rockstar сработал.

### Установка и обновление на Linux

- Установка с GitHub — быстро и без обрывов:

  ```bash
  curl -fsSLo flovmp-get.sh https://github.com/shizeexgod/FloV-MP-releases/releases/latest/download/get.sh
  sudo bash flovmp-get.sh --github shizeexgod/FloV-MP-releases --key FLV-XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX
  ```

- Обновление потом — одна команда: `sudo bash /opt/flovmp/update.sh`
  (ключ и источник обновлений запоминаются при установке).
- Второй сервер на той же машине больше не ломает базу первого: установка
  останавливается и подсказывает свои имена (`--db-name`, `--db-user`,
  `--service`, `--port`).
- Установщик предупреждает, если в системе выключен IPv6 — с ним сервер
  падает на старте с «Failed to create host».

### Новые миграции базы

`003_vehicles.sql`, `004_players.sql`, `005_player_data_key_case.sql` —
применяются сервером сами при старте. Ваши миграции с номера 100 не трогаются.
