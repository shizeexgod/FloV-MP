# Подключение лаунчера проекта к FloV:MP

FloV:MP поставляет сервер и клиентский комплект. У проекта может быть свой
лаунчер и свой бренд. Для входа игрока лаунчеру нужен **публичный адрес VDS
проекта**; адрес сервиса лицензий относится только к серверной активации.
Лицензионный ключ и `license.flv` не передаются игрокам и не вшиваются в
лаунчер.

## Контракт запуска (GTA V Legacy 1.0.3889.0)

1. Владелец ставит сервер на своей VDS. `install.sh --public-host <host>` или
   Windows `install.ps1` создаёт `client-b3889/server.txt` с
   `address=<host>:<game-port>`. Если адрес не определён, владелец вписывает
   его сам до раздачи клиентского комплекта. При обновлении существующий
   `server.txt` сохраняется.
2. Лаунчер проекта распространяет `client-b3889` и вызывает
   `play.cmd <host>:<game-port> [nickname]` из этой папки. Если параметр адреса
   не задан, `play.cmd` читает `server.txt` рядом с собой. Для явного пути к
   GTA V он может передать `FLOVMP_GTA_PATH` в окружении процесса.
3. `play.ps1` проверяет адрес и порт, устанавливает клиент при необходимости,
   синхронизирует моды до запуска GTA, затем записывает запрос подключения в
   `%LOCALAPPDATA%\FloVMP\connect.txt`. Нативный клиент подключается к
   **порту игры + 10** (пример: `7788` → `7798`). Если GTA уже запущена, он
   читает новый запрос без перезапуска.
4. Веб-кнопка может открыть `flovmp://connect/<host>:<game-port>` после
   регистрации протокола клиентским установщиком. Игрок подтверждает переход.

Лаунчер может узнать текущий адрес из публичного
`GET /api/v1/public/<project-slug>/connection` на центральном портале. Ответ
содержит `server.endpoint`, `server.gatewayPort`, `server.online` и
`launch.protocolUrl`; никаких ключей лицензии или токенов агента в нём нет.
Endpoint берётся только из production-сервера этого проекта. Если публичный
адрес ещё не настроен, API возвращает `409`, поэтому лаунчер не должен
подставлять чей-либо IP по умолчанию. Ответ не кешируется, чтобы переезд VDS
отражался без пересборки лаунчера.

Пример для стороннего лаунчера на Windows:

```bat
set "FLOVMP_GTA_PATH=C:\Games\Grand Theft Auto V"
call "C:\Project\client-b3889\play.cmd" "play.example.com:7788" "Player_Name"
```

`<host>` должен разрешаться на VDS владельца; для нескольких серверов проект
передаёт нужный адрес при каждом запуске. Нельзя брать адрес из нашего
центрального сервиса лицензий и нельзя подставлять IP первого покупателя.

## Порты и проверка

При стандартном `game-port=7788` владелец проверяет доступность `7788`
(игровой порт), `7798/TCP+UDP` (шлюз клиента), `7895/TCP+UDP` (публичный
голосовой порт) и `7808/TCP` для модов, если используется встроенная раздача.
Порт голоса и раздачи модов может быть переопределён настройками сервера; внешний API
авторизации `7799` открывают только когда он действительно нужен.

Проверка цепочки на VDS клиента: сервер активирован и слушает порты; в
`client-b3889/server.txt` указан его публичный адрес; лаунчер вызывает
`play.cmd` с этим адресом; в `%LOCALAPPDATA%\FloVMP\connect.txt` появляется
адрес с портом +10; игрок видит вход именно на свой проект. Последний шаг
нужно проверить в GTA на Windows, его нельзя подтвердить сборкой на Mac.
