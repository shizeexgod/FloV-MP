# Быстрый прогон: клиент GTAMP → сервер FloV:MP (задача #18a)

Обновлено: 2026-08-28
Цель: проверить связку «наш сервер 16.4.39 + C#-геймод ↔ настоящий клиент alt:V»,
не дожидаясь своего лаунчера. Дальше — перенос сервера, потом свой лаунчер.

## Что подготовлено

- **Сервер запущен** мной в фоне (`runtime/server/altv-server.exe`, `:7788`,
  `[C#] core: server fully started`). Если ПК перезагрузился / упал:
  ```
  powershell -File C:\FloV-MP\scripts\run-server.ps1
  ```
- **Клиент GTAMP** скопирован в `C:\FloV-MP\runtime\gtamp-client\`
  (`connect.exe` + `packs\mp1..7.pack`), `.config` уже правлен под твою
  Epic-установку GTA V (`C:\Program Files\9d2d0eb64d5c44529cece33fe2a46482`).

## Прогон (владелец, на этой машине)

```
C:\FloV-MP\runtime\gtamp-client\connect.exe -connect 127.0.0.1:7788
```

Что произойдёт:
1. `connect.exe` первый раз распакует ~350 МБ из `.pack` в скрытую папку
   `%LOCALAPPDATA%\<хэш>` (1–2 минуты, без окна).
2. Поднимет локальный `proxy.dll` (HTTP `127.0.0.1:9988`) — заглушки вместо
   мёртвого CDN alt:V.
3. Сгенерит `altv.toml`, запустит `altv.exe -directlaunch` → GTA V через alt:V.

**Ожидаемо:** загрузочный экран alt:V → на чёрном фоне **NUI логина FloV:MP**
(розовый акцент) → регистрация → спавн на Legion Square → HUD → `T` чат →
`I` инвентарь. Полный чек-лист — `docs/instructions/live-test-guide.md`.

## Второй игрок (заказчик, другой ПК)

Нужно: папка `runtime\gtamp-client\` целиком + внешний IP владельца +
проброшенный порт **7788 (TCP и UDP)**.

1. В `client-new\.config` (или `gtamp-client\.config`) поставить свой
   `gta_path`.
2. `connect.exe -connect <внешний-IP-владельца>:7788`

## Если не заводится — что это значит

| Симптом | Вывод / следующий шаг |
|---|---|
| `connect.exe` молча закрылся, GTA не стартовала | смотреть `%LOCALAPPDATA%\<хэш>\logs\connect.log` и `proxy_access.log`. Вероятно, `gtaPlatform='steam'` (GTAMP хардкодит Steam, у тебя Epic). |
| alt:V ругается «cannot verify version» / висит на Connecting | прокси GTAMP не перехватил запрос клиента к CDN. Значит их схема завязана на что-то ещё (патч `altv.exe`?) → идём в задачу #19 (свой коннектор). |
| Загрузился, но вместо логина FloV:MP — чужой UI / ошибка ресурса | `hashClientResourceName` или клиентский ресурс не отдался. Проверить `server.log`. |
| Логин FloV:MP есть, регистрация/вход работают, спавн, HUD, чат, инвентарь | **успех.** Связка ядра рабочая. Фиксируем в `agent_state.md` #18, идём к переносу сервера. |
| Второй игрок зашёл, оба видят педов, чат общий | **полный успех ядра.** |
