# Чек-лист установки FloV:MP на сервер клиента

Пошагово, по порядку. Каждый пункт — то, что реально ломалось, а не
формальность. Время целиком: 30–40 минут, из них половина — проверка.

---

## Перед выездом (на своей машине)

```bash
python scripts/flovmp_healthcheck.py --build
```

Должно быть **0 провалов**. Если что-то красное — установку не начинать:
проверка ловит ровно те поломки, которые на сервере клиента проявятся молча.

Собрать пакет:

```bash
python scripts/pack_server.py --os linux
```

Результат — `dist/server/flovmp-server-<версия>-linux.tar.gz` (+ `.sha256`).
Сборщик сам проверяет, что в пакете есть `sql/migrations`, голосовой сервер,
ресурсы, и что в него **не попали** `admins.json`, `license.flv`, настройки и
SocialClub владельца. Любая ошибка — пакет не создаётся.

---

## Установка

```bash
tar -xzf flovmp-server-<версия>-linux.tar.gz
cd flovmp-server-<версия>-linux
sudo ./install.sh --name "Название" --slots 1000 --owner-sc <SocialClubId владельца>
```

Скрипт сам: проверяет целостность пакета, ставит зависимости и .NET 8,
создаёт базу и отдельного пользователя MariaDB со случайным паролем,
настраивает голос (секрет, публичный адрес), регистрирует службы
`flovmp` и `flovmp-voice`, запускает и проверяет по логу загрузку ресурсов,
миграции и подключение голоса.

Если внешний IP не определяется автоматически — `--public-host <ip-или-домен>`.
Обновление — тот же `./install.sh` из нового пакета (бэкап и откат автоматически).
Все параметры: `./install.sh --help`.

## Проверка сразу после установки

### 1. Ресурсы действительно загрузились

Самая коварная поломка: сервер пишет `Server started`, слушает порт, **ни
одной ошибки в логе** — и не загрузил ни одного ресурса. Пустой мир.

```bash
grep -E "Loading resource|\[C#\]" /opt/flovmp/server/server.log | head
```

Должны быть строки `Loading resource flovmp-starter` и `[C#] [FloV:MP ...`.
Если их нет — смотреть `modules` и `resources` в `server.toml`: **они обязаны
стоять ДО первой секции `[...]`**. В TOML ключ после `[threads]` читается как
`threads.modules`, то есть не читается вовсе.

### 2. База, а не JSON

```bash
grep -E "\[DB\]" /opt/flovmp/server/server.log
```

Ожидается `Успешное подключение к MariaDB` и строка про миграции. Если видно
`Переход на локальное хранилище` — база не подключилась, и данные пишутся в
файл. Дальше идти нельзя.

### 3. Голос

```bash
grep -A3 "\[voice\]" /opt/flovmp/server/server.toml
grep -c "Connected to alt:V server" /opt/flovmp/voice/voice.log
```

Нужны: секция `[voice]` в конфиге игрового сервера и хотя бы одна строка
`Connected to alt:V server` в логе голосового. Порт из `externalPublicPort`
должен быть открыт **и по TCP, и по UDP**:

```bash
ufw allow 7895/tcp && ufw allow 7895/udp
```

Частая ошибка: `externalPublicHost = "127.0.0.1"`. Тогда клиент пытается
подключиться сам к себе, и голоса нет — молча, без ошибок где-либо.

### 4. Снаружи

С любой другой машины:

```bash
python scripts/flovmp_healthcheck.py --server <ip-сервера>
```

Проверит игровой порт, голосовой порт и то, что гейммод представился (то есть
C#-ресурс действительно стартовал, а не просто порт слушается).

## Проверка вживую (не пропускать)

Автоматика сюда не достаёт. Нужны два человека в игре.

| Что | Как | Что должно быть |
|---|---|---|
| Вход | зарегистрировать аккаунт, перезайти | аккаунт сохранился |
| Голос | встать рядом, говорить | слышно; на расстоянии 30+ м — нет |
| Мут голоса | `/vmute <id>` | игрока перестало быть слышно, повторный вызов вернул |
| Бан по железу | `/hwidban <id> 1 тест` | с **нового аккаунта** зайти не даёт |
| Разбан | `/unban <ник>` | заходит снова |
| Рестарт | перезапустить службу | баны и аккаунты на месте |

Последняя строка важнее, чем кажется: до сентября баны жили только в памяти и
снимались любым рестартом.

## Что передать клиенту

1. Токен настройки из лога (`[FloV:MP Setup] Initial setup token:`) — по нему
   он забирает права владельца командой `/claimowner <токен>`.
2. Порты, которые должны быть открыты: `7788` (игра), `7895` (голос), плюс
   `7799`, если нужен внешний доступ к API.
3. Предупреждение про BattlEye: если у игрока не запускается игра, он
   отключает BattlEye в настройках Rockstar Games Launcher сам. Лаунчер
   покажет эту инструкцию автоматически, но лучше сказать заранее.
4. `FLOVMP_ADMIN_PASSWORD` — задать в `flovmp.env`, иначе вход по `/alogin`
   не работает вовсе (это намеренно: дефолтного пароля больше нет).

## Если что-то пошло не так

| Симптом | Куда смотреть |
|---|---|
| игрок висит в пустом мире | ресурсы не загрузились — пункт 1 |
| данные пропадают после рестарта | база не подключилась — пункт 2 |
| голоса нет ни у кого | пункт 3, чаще всего файрвол или `127.0.0.1` |
| сервер замирает на минуты | смотреть `resourceManager.Update() took:` в логе |
| бан не держит | проверить, что `[Ban]` в логе говорит про MariaDB, а не про файл |
| игра не запускается у игрока | `%LOCALAPPDATA%\FloVMP\connect.log`, искать `[be]` |
