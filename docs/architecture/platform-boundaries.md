# Границы платформы FloV:MP и сервера Florida V

Этот документ фиксирует два разных продукта, которые работают вместе.

## FloV:MP

FloV:MP — собственный multiplayer-движок и клиентская платформа. Он отвечает за:

- запуск клиентского runtime и прямое подключение к адресу сервера;
- сетевой транспорт и синхронизацию сущностей;
- загрузку ресурсов сервера;
- совместимость с GTA V Legacy и GTA V Enhanced через отдельные профили;
- лаунчер, проверку файлов, обновление клиентского runtime и диагностику.

У FloV:MP не будет общего master list. Точка входа — лаунчер конкретного проекта и
прямой connect URL.

## Florida V

Florida V — отдельный RP-сервер/гейм-мод, который работает поверх FloV:MP. Он
отвечает за:

- авторизацию и аккаунты;
- персонажей, фракции, бизнесы и семьи;
- инвентарь, экономику, транспорт и игровой прогресс;
- HUD, меню, чат и прочие клиентские ресурсы;
- админ-панель и аудит действий.

Игровая логика Florida V не должна попадать в ядро FloV:MP. Это позволяет обновлять
движок и запускать другие серверы без копирования RP-логики.

## Практическое правило структуры

```text
FloV:MP
├── launcher/          # выбор GTA-профиля и direct connect
├── client runtime/    # общий клиентский runtime
└── server runtime/    # общий сетевой серверный runtime

Florida V
├── server resources/  # C#-логика RP
├── client resources/  # JS/HTML HUD и игровые интерфейсы
└── admin/             # права, проверки и логи проекта
```

Изменение механики Florida V — задача серверного проекта. Исправление синхронизации,
загрузки ресурсов или запуска GTA — задача FloV:MP.
