# Сторонние компоненты

FloV:MP source-kit содержит собственный серверный код, клиентские ресурсы,
SDK, скрипты сборки и документацию. Он не передаёт покупателю права на GTA V,
alt:V или библиотеки третьих сторон.

## alt:V runtime

Папка `engine/` намеренно не входит в обычную выгрузку source-kit. Для сборки
готового runtime-пакета владелец проекта должен отдельно получить разрешённый
дистрибутив alt:V: при экспорте исходников передать его через `--altv-backup`
вместе с `--include-altv-engine`, а после распаковки выгрузки — положить
разрешённый runtime в локальную `engine/` перед запуском `pack_server.py`.
Нельзя продавать, публиковать или перепаковывать клиентские/серверные бинарники
alt:V как собственные без проверки актуальных условий и отдельного разрешения,
если оно требуется.

## NuGet и системные зависимости

Пакеты .NET, MariaDB, .NET Runtime и прочие зависимости остаются собственностью
их правообладателей и устанавливаются/распространяются на их условиях.

Перед коммерческой передачей проверьте актуальные лицензии каждого бинарного
компонента, который добавляется в runtime-пакет. Этот файл не является
юридическим заключением.
