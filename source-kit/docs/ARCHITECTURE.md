# Архитектура сервера FloV:MP

## Процессы

| Процесс | Что делает |
|---|---|
| `flovmp-server` (alt:V 16.4.39) | игровой сервер: сеть, синхронизация, стриминг; загружает ресурсы |
| `altv-voice-server` | голосовой сервер; игроки подключаются к нему напрямую по UDP |

Игровой сервер загружает модули `csharp-module` (ресурсы на C#) и `js-module`
(клиентские скрипты) и ресурсы из списка `resources` в `server.toml` по порядку.

## Ресурсы

| Ресурс | Проект | Назначение |
|---|---|---|
| `flovmp-starter` | `server/src/FloVMP.Starter` | базовая платформа (по умолчанию) |
| `flovmp-client` | `client/resources/flovmp-client` | клиентская часть: чат, консоль F8, вход, загрузка, HUD, NoClip/ESP для администраторов |
| `flovmp-core` | `server/src/FloVMP.Gamemode` | полный RP-режим — пример построения геймода на Core |
| `gamemode` | папка `gamemode` в пакете | сервер владельца, создаётся из `sdk/template` |

`flovmp-starter` и `flovmp-core` — альтернативы: на сервере работает один из них.

### Базовая платформа (flovmp-starter)

- спавн, смерть и возрождение;
- чат: общий, `/me`, `/do`, `/b`, `/s`, `/w`; ограничение частоты и очистка текста;
- администрирование: 8 уровней, дежурство (`/alogin`, `/aduty`), телепорты, транспорт, NoClip, ESP, модерация;
- блокировки по Social Club, IP, HWID, MAC — с синхронизацией между инстансами;
- голосовой канал (пространственный, 25 м) и мут голоса;
- проверка лицензии и лимит игроков;
- консоль сервера: `setadmin`, `reloadadmins`, `ban`, `unban`, `bans`, `kick`, `online`, `license`;
- API для своих ресурсов: события `flovmp:commands:register`, `flovmp:command`,
  `flovmp:player:ready`, `flovmp:platform:ready` (см. `DEVELOPMENT.md`).

### RP-режим (flovmp-core)

Аккаунты с логином и паролем, HUD, инвентарь с предметами на земле, экономика
(наличные, банк, переводы), фракции и звания, документы и лицензии, дома,
тюрьма, античит (скорость, телепорт, урон, оружие, физика транспорта),
HTTP-API для лаунчера (`/api/auth/*`, `/info`).

## Потоки

Сущности alt:V (игроки, транспорт) трогаются **только с главного потока**:
из обработчиков событий и `OnTick`. Всё медленное — в фоне:

- проверка пароля (PBKDF2) и запросы к базе при входе — `Task.Run`, результат
  применяется в `OnTick` (`AuthSystem.Pump`);
- запись аккаунтов — очередь `WriteBehindQueue`;
- сверка администраторов и банов с базой — раз в 30 секунд в фоне, применение
  к игрокам — на главном потоке;
- отложенные действия с игроками — `MainThreadScheduler`.

## Данные

| Что | MariaDB | Без базы |
|---|---|---|
| аккаунты (RP) | `accounts` | `server/flovmp-data/accounts.json` |
| блокировки | `bans` | `server/flovmp-data/bans.json` |
| администраторы | `admins` | `server/config/admins.json` |
| инвентари | — | `server/flovmp-data/inventories.json` |

База подключается, если задан `FLOVMP_DB_PASSWORD` (или `FLOVMP_DB_CONNECTION`).
Если база недоступна, сервер работает на файлах и пишет об этом в лог.

Схема — `sql/migrations`. `MigrationRunner` при старте применяет новые файлы
по порядку, ведёт `schema_migrations` с контрольными суммами и берёт
`GET_LOCK`, чтобы несколько инстансов не мигрировали одновременно.
Номера 001–099 — платформа, 100+ — свои таблицы владельца.

## Безопасность

- права администратора выдаются только по SocialClubId (ник подделывается);
  источник — таблица `admins`, `server/config/admins.json`, `FLOVMP_OWNER_SC`,
  одноразовый токен `/claimowner`;
- силовые команды не действуют на администраторов равного и старшего уровня;
- все события от клиента проверяются на сервере (права, аргументы, частота);
- пароли — PBKDF2-SHA256; ограничение попыток входа и регистраций;
- HTTP-API слушает только localhost, если не задан `FLOVMP_API_BIND=public`;
- лицензия — `license.flv` с подписью RSA-2048, проверка локальная.

## Лицензия

`LicenseFile` проверяет подпись открытым ключом портала, водяной знак и срок
(плюс 7 дней отсрочки). Без действующей лицензии сервер работает с лимитом
32 игрока. Открытый ключ — `LicenseFile.AuthorityPublicKeyPem`.

## Переменные окружения (`config/flovmp.env`)

| Переменная | Назначение |
|---|---|
| `FLOVMP_DB_HOST`, `_PORT`, `_NAME`, `_USER`, `_PASSWORD` | база данных |
| `FLOVMP_DB_CONNECTION` | строка подключения целиком (вместо полей выше) |
| `FLOVMP_DB_MIGRATE=0` | не применять миграции автоматически |
| `FLOVMP_DB_POOL_MIN`, `FLOVMP_DB_POOL_MAX` | размер пула соединений |
| `FLOVMP_OWNER_SC` | SocialClubId владельца (уровень 8) |
| `FLOVMP_SETUP_TOKEN` | токен для `/claimowner` |
| `FLOVMP_ADMIN_PASSWORD` | пароль `/alogin` перед дежурством |
| `FLOVMP_LICENSE_KEY` | ключ лицензии (license.flv должен быть выдан на него) |
| `FLOVMP_LICENSE_FILE` | путь к license.flv, если он не в корне установки |
| `FLOVMP_MODE=full` | RP-режим в `flovmp-core` |
| `FLOVMP_API_PORT`, `FLOVMP_API_BIND`, `FLOVMP_API_CORS_ORIGIN` | HTTP-API RP-режима |
| `FLOVMP_TELEMETRY_URL`, `FLOVMP_COMMAND_URL`, `FLOVMP_AGENT_TOKEN` | связь с порталом (необязательно) |

## Установка и обновление

`scripts/pack_server.py` собирает пакет: движок (переименованный), ресурсы,
шаблоны настроек, миграции, SDK и `manifest.txt` / `manifest.json` со списком
файлов платформы и контрольными суммами. Всё, чего нет в манифесте, — файлы
владельца, их обновление не трогает.

Linux: `install.sh` ставит зависимости, .NET 8, MariaDB, создаёт пользователя
базы со случайным паролем, службы systemd `flovmp` и `flovmp-voice`, проверяет
запуск по логу; при обновлении делает резервную копию и откатывается при сбое.

Windows: `FloVMP-Server.exe` создаёт настройки при первом запуске, запускает
голосовой и игровой серверы в одном окне и останавливает их вместе.
