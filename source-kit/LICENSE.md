# Лицензия на исходный код FloV:MP

Правообладатель: FloV:MP (далее — Правообладатель).
Лицензиат: лицо, получившее исходный код по договору с Правообладателем.

## 1. Что предоставляется

1.1. Бессрочная неисключительная лицензия на использование исходного кода
серверной части мультиплеера FloV:MP (сервер, клиентские скрипты, база
данных, скрипты сборки и установки) в составе **одного RP-проекта**
Лицензиата.

1.2. Лицензиат вправе изменять и дорабатывать исходный код под задачи своего
проекта, собирать из него сервер и запускать его на любом количестве своих
серверов этого проекта.

## 2. Что остаётся за Правообладателем

2.1. Исключительные права на исходный код, название FloV:MP и связанный
брендинг принадлежат Правообладателю и Лицензиату не передаются.

2.2. Лицензия не даёт права использовать название и брендинг FloV:MP для
продвижения собственных продуктов Лицензиата.

## 3. Запрещено

3.1. Перепродавать исходный код или собранный из него сервер.

3.2. Публиковать исходный код, в том числе частично, в открытом доступе.

3.3. Передавать исходный код третьим лицам, включая другие проекты,
в том числе безвозмездно.

3.4. Использовать исходный код для другого проекта, кроме указанного в договоре.

## 4. Прочее

4.1. Исходный код предоставляется «как есть». Поддержка и обновления —
по отдельной договорённости.

4.2. Сторонние компоненты (движок alt:V, библиотеки NuGet) распространяются
на условиях их правообладателей.

4.3. Нарушение раздела 3 прекращает действие лицензии.
