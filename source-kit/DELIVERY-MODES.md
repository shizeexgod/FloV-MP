# Два независимых продукта FloV:MP

Репозиторий не смешивает два варианта поставки.

## Обычная лицензия — runtime-пакет

Собирается отдельной командой:

```bash
python scripts/pack_server.py --os linux
python scripts/pack_server.py --os windows
```

Покупатель получает готовые файлы для запуска сервера, шаблоны настроек,
установщик и SDK для своего ресурса. Исходники платформы, `web/`, полноценный
launcher и внутренний connector в обычный пакет не входят. В корне пакета лежит
`delivery.json` с машинно-читаемым режимом `runtime-license`.

## Расширенная лицензия — source-kit

Выгружается отдельным экспортёром:

```bash
python scripts/export_source.py --out ./deliveries/source
```

Покупатель получает собственный серверный код, клиентские ресурсы, SDK,
тесты, скрипты сборки/установки и документацию для кастомизации. `web/` и
launcher намеренно остаются вне выгрузки. Сторонний alt:V runtime не добавляется
по умолчанию; его можно включить только отдельным явным флагом при наличии прав
на передачу. В корне распакованной выгрузки лежит `SOURCE-MANIFEST.json` с
режимом `source-kit`, размерами и SHA-256 всех файлов.

Если runtime был получен отдельно, его импорт выполняется до сборки пакета:

```bash
python scripts/prepare_engine.py --source /path/to/runtime.zip --dest engine --platform all
python scripts/pack_server.py --os all
```

Импортёр принимает только обычные файлы, отклоняет traversal/symlink в архиве,
проверяет обязательную структуру обеих ОС и создаёт `engine/ENGINE-MANIFEST.json`.
Он не является разрешением на перепродаж alt:V — права на внешний runtime
проверяются отдельно владельцем поставки.

Эти команды не являются взаимозаменяемыми: runtime-пакет не превращается в
исходники, а source-kit не считается готовым runtime-пакетом без разрешённого
стороннего engine.
