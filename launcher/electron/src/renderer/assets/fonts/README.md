# Шрифты лаунчера

Основной шрифт интерфейса — **Proxima Nova** (как у Majestic Launcher).

Proxima Nova — коммерческий шрифт (Mark Simonson Studio). Файлы `.ttf`
в репозиторий НЕ кладём — это лицензируемое ПО. Когда лицензия куплена,
положите сюда 4 файла и они подхватятся автоматически (`@font-face`
в `styles.css` уже настроен):

    ProximaNova-Regular.ttf
    ProximaNova-Semibold.ttf
    ProximaNova-Bold.ttf
    ProximaNova-Black.ttf

Пока файлов нет — используется бесплатный запасной шрифт **Mulish**
(Google Fonts), максимально близкий по рисунку.
