# Звуки интерфейса лаунчера

Сюда кладутся звуковые сэмплы. Формат — `.ogg` (предпочтительно) или `.mp3`,
моно, короткие (10–200 мс), без «хвоста»/реверба, −6…−12 dBFS.

Движок (`SND` в `renderer.js`) грузит файл по имени; если файла нет —
временно синтезирует короткий тон, чтобы фича работала. Как только файл
появится в этой папке, он подхватится автоматически (перезапуск лаунчера).

| Имя файла      | Когда играет                                  | Громкость |
|----------------|-----------------------------------------------|-----------|
| `hover.ogg`    | наведение на кликабельный элемент             | 0.30      |
| `click.ogg`    | клик по кнопке / пункту                       | 0.55      |
| `select.ogg`   | выбор опции в списке, подтверждение           | 0.50      |
| `modal.ogg`    | открытие окна (настройки, кабинет, новость)   | 0.55      |
| `modalOut.ogg` | закрытие окна                                 | 0.45      |
| `toggle.ogg`   | переключение тумблера / чекбокса              | 0.40      |
| `error.ogg`    | ошибка (неверный пароль и т.п.)               | 0.60      |

Отключить звук для поддерева DOM — атрибут `data-no-sound` на контейнере.
Мастер-громкость и вкл/выкл — настройка «Звук в интерфейсе».

## Где взять сэмплы (свободные лицензии)

- **Kenney — UI Audio** (`kenney.nl/assets/ui-audio`) и **Interface Sounds**
  (`kenney.nl/assets/interface-sounds`) — CC0, 50 + 100 чистых UI-звуков
  (клики, переключатели, подтверждения). Лучший вариант «из коробки».
- **SFXMint — UI** (`sfxmint.com/category/ui`) — CC0, сухие one-shot'ы.
- **CAPTNPHANTOM — Free Essential UI Sound Pack** (itch.io) — 28 звуков, WAV.
- **Pixabay — UI sounds** (`pixabay.com/sound-effects/search/ui`) — royalty-free,
  без атрибуции.

WAV из паков конвертировать в `.ogg` (напр. `ffmpeg -i in.wav -c:a libvorbis -q:a 4 out.ogg`).
